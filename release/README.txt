BEYOND GOOD AND EVIL - ARCHIPELAGO
==================================

Requirements
- Beyond Good and Evil for PC (Steam version). The game can be installed in ANY folder:
  nothing is copied into the game folder. The client finds the running game (BGE.exe) by itself.
- Archipelago 0.6.4 or newer: https://archipelago.gg

Install
1. Copy "bge.apworld" into the "custom_worlds" folder of your Archipelago installation
   (for example C:\ProgramData\Archipelago\custom_worlds\).
2. Edit "Beyond Good and Evil.yaml" (set your slot name) and give it to whoever generates the multiworld.
   Whoever GENERATES the multiworld also needs bge.apworld in their custom_worlds folder.

Play
1. Start Beyond Good and Evil and load a save (a new game works).
2. Open the Archipelago Launcher and start "Beyond Good and Evil Client".
3. Type:  /connect <server address>:<port>   and enter your slot name.
4. Play. Checks are sent automatically; received items appear in the game.

Notes
- The game has no windowed mode and may crash on Alt+Tab. Pause the game before switching windows.
- Project page, documentation and issues:
  https://github.com/cplara/beyond-good-and-evil-archipelago

ESPANOL
1. Copia "bge.apworld" a la carpeta "custom_worlds" de Archipelago.
2. Edita "Beyond Good and Evil.yaml" (tu nombre de slot) y entregalo a quien genere la partida.
   Quien genera tambien necesita bge.apworld.
3. Abre el juego y carga una partida (sirve una nueva). No hay que copiar nada a la carpeta del juego.
4. En el Launcher de Archipelago abre "Beyond Good and Evil Client" y escribe /connect <servidor>:<puerto>.
5. Evita Alt+Tab: el juego puede cerrarse. Pausa antes de cambiar de ventana.
